# 输入框 Slash 命令

在任务输入框开头输入 `/` 打开菜单。继续输入命令名或中文说明可筛选，例如 `/st` 或 `/历史`。完整名称优先，其次是名称前缀，再匹配说明。使用 ↑ / ↓ 选择、Enter 执行、Esc 关闭菜单，也可点击菜单项。Shift + Enter 仍然换行，中文输入法确认候选词不会执行命令。

只有去除开头空白后以单个 `/` 开头的内容进入命令模式。正文中的 `/` 和 URL 仍是普通消息。要发送以 `/` 开头的文本，请输入 `//`：例如 `//help` 会发送普通消息 `/help`。未知命令、额外参数或附带图片的命令都会明确提示并保留草稿，不会作为消息发给模型。

## 已实现的范围

首批命令使用项目已有的网页流程和网关接口，不向终端输入文字，也不透传任意 Codex CLI 命令。实现范围依据本机 Codex **0.162.1** 与仓库中已经验证的 app-server 接口。CLI 自身的完整命令范围独立维护，可查阅 [Codex CLI 命令参考](https://learn.chatgpt.com/docs/developer-commands?surface=cli)。

所有命令均无需参数。

| 命令      | 本网页中的行为                             | 前置条件与边界                                                                                                                                                 |
| --------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/help`   | 在输入框旁显示本网页可用命令的说明         | 本地展示，离线也可使用                                                                                                                                         |
| `/new`    | 在当前项目创建会话，确认成功后切换到新会话 | 使用项目默认设置；需要可用项目及 `thread/start` 能力；不受原会话执行状态影响                                                                                   |
| `/fork`   | 复制当前会话已保存的历史并切换到副本       | 需要非空历史及 `thread/fork` 能力；保留现有 Fork 语义，原会话运行、被其他进程占用或有其他待核对提交时仍可复制；同一 Fork 未确认时不能重复提交                  |
| `/resume` | 恢复当前选中的历史会话                     | 需要 `thread/resume` 能力；这不是 CLI 的会话选择器，不接受会话 ID；从左侧选择历史后使用，保留该会话已保存的配置；占用失败后可显式重试，由 Codex 重新判断写入锁 |
| `/stop`   | 请求中断当前受管会话的活动任务             | 网页快捷命令，需要 `turn/interrupt` 能力；不接管或停止其他进程；兼容性尚待确认时仍可中断已有任务                                                               |
| `/status` | 打开已有的连接、运行状态和提交诊断面板     | 本地打开面板，不声称刷新已经完成；使用面板中的刷新与核对按钮获取新状态                                                                                         |

菜单始终显示命令的说明和用法；不可用项显示具体原因，包括离线、登录失效、Codex 不可用、兼容性未确认、未选项目或会话、目录不可用、空历史、正在运行、执行占用、请求未确认以及接口能力缺失。`/resume` 不会凭外部历史中保存的活动状态认定会话仍被占用，恢复时以 Codex 的写入锁为准；本服务已有尚未结束的执行标记仍必须先核对。

## 回执、草稿和故障处理

执行操作复用网页现有的操作 ID、`workspace.run`、回执追踪和错误提示。只有 `acknowledged` 才显示操作已被接受；新建和 Fork 还必须收到目标会话 ID，才显示成功并将反馈归属到新会话。中断成功只表示“已提交中断请求”，任务是否结束以之后的真实状态为准。

失败、缺少回执、`accepted`、`dispatching` 或 `unknown` 都保留命令输入。网络异常沿用现有操作 ID 查询，不自动重发；先查看页面错误或使用 `/status` 核对。命令执行时会重新核验当前状态，项目或会话已经切换时拒绝使用旧命令上下文；提交期间重复 Enter 或点击不会重复执行同一草稿。

普通消息和图片仍按原流程发送、追加要求；命令不会创建用户消息或污染对话历史。成功只清除本次已执行且未被继续编辑的命令输入，其他会话和项目草稿继续独立保存。

## 实现入口与验证

- `src/web/lib/slash-commands.ts`：命令解析、筛选、校验、可用状态、网关动作和回执解释。
- `src/web/components/Composer.tsx`、`SlashCommandMenu.tsx`：输入交互、键盘/输入法行为、草稿与反馈。
- `src/web/App.tsx`：提供当前项目、会话和运行状态，复用工作空间动作及诊断面板。
- `tests/web/slash-commands.test.ts`：解析、状态守卫、动作参数、回执与上下文变化。
- `tests/e2e/slash-commands.spec.ts`：实际浏览器验证菜单、键盘、命令流程、错误、草稿、普通消息和移动端。

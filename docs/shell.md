# Shell 命令执行面板

点击工作区顶部的 **Shell** 打开面板。输入命令后点击 **执行命令**，或按 Ctrl / ⌘ + Enter。标准输出和错误输出实时更新，错误输出使用红色，结束后显示状态及退出码；**中断命令** 请求 Codex 终止正在执行的进程。

首版是命令执行面板，不是完整交互式终端：没有 PTY、标准输入、终端模拟、编辑器、密码提示或交互式 REPL。每次启动独立进程；macOS / Linux 使用 `/bin/sh -c`，Windows 使用 `cmd.exe /d /s /c`。`cd`、环境变量等只影响本次命令，下一次仍从面板显示的项目根目录启动。

## 项目归属与生命周期

- 面板始终跟随当前项目，明确显示项目名和服务端真实工作目录。切换同一项目的会话使用同一个面板；不同项目的命令、输出和输入草稿分开。其他项目运行中的命令会有提示，顶部入口显示运行数量。
- 收起、关闭面板、切换项目、关闭页面或浏览器断线都不会停止命令。需要停止时，切回所属项目点击 **中断命令**。关闭再打开仍可查看服务端保留的近期记录。
- 每个项目最多运行一条命令，总共最多四条。运行期间不能移除所属项目，受管升级等待命令结束。每条命令最长运行十分钟，由 Codex 的命令超时机制终止。
- 近期命令可从下拉列表选择，点击 **复用命令** 放回输入框，检查后再次执行。记录只保存在当前服务进程内，跨项目合计保留最近二十条；每条最多保留 64 KiB 输出（标准输出、错误输出分别限制 32 KiB），最多二百个输出片段。达到限制会标明截断。
- 页面断线时保留已收到的输出并禁用新执行，自动重连后核对状态。提交响应丢失时，不创建新操作重发；**核对并重试原提交** 使用原操作 ID，复用已有的持久回执，避免重复执行。服务重启后不能恢复输出记录；仍留在页面上的活动记录会标为结果未知。
- Covro 到 Codex 的执行连接断开时，Codex 会终止该连接所属命令；Covro 保留收到的输出并显示结果未知，不推测退出码，也不会自动重新执行。重启或强制关闭服务会终止命令，不适合借此托管后台守护进程。

## 权限与协议

所有读取、执行和中断请求复用现有 Host、Origin、Cloudflare Access 身份验证、请求体校验、升级维护门禁及 Codex 兼容性确认。浏览器只能提交已注册项目 ID，不能指定工作目录、环境变量或沙箱覆盖。每次启动前重新核实目录可访问且真实路径未发生变化。

执行使用 Codex `command/exec`，流式接收 `command/exec/outputDelta`，中断使用 `command/exec/terminate`。不会创建会话或发送模型请求。接口缺失时报告失败，不回退到 Covro 宿主直接执行。

执行沿用 **Codex app-server 自身配置的沙箱策略**，不覆盖为完全访问；会话内临时授权、会话权限选择和审批流程不适用于这些独立命令。沙箱阻止的操作会直接失败，不提供面板内提权。项目目录是启动目录，文件系统与网络访问范围仍由 Codex 沙箱决定；如 Codex 配置本身为完全访问，命令也具有相应权限。

版本依据：仓库生成的 Codex 0.163.0 `CommandExecParams`、`CommandExecOutputDeltaNotification` 和 `CommandExecTerminateParams`；参见 [Codex App Server 官方文档](https://learn.chatgpt.com/docs/app-server)。
